# Optimization Courses Website

Static GitHub Pages site for optimization course materials.

## Files

- `index.html` — main webpage with SEO metadata and structured data
- `styles.css` — styling
- `sitemap.xml` — search engine sitemap
- `robots.txt` — crawler instructions

## Publish on GitHub Pages

1. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload these files to the repository root.
3. Go to Settings → Pages.
4. Select `Deploy from a branch`, branch `main`, folder `/root`.
5. Visit `https://YOUR-GITHUB-USERNAME.github.io/`.

## SEO setup after publishing

1. Replace all instances of `https://alireza-soroudi.github.io/` with your final website URL if different.
2. Replace placeholder `sameAs` links in `index.html` with your real Google Scholar, ORCID, LinkedIn, GitHub, and university profile links.
3. Replace `mailto:your.email@example.com` with your real public email address.
4. Submit `sitemap.xml` in Google Search Console.
