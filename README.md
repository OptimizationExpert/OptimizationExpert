# Optimization Courses Website

A static personal webpage for optimization courses, ready for GitHub Pages.

## How to publish on GitHub Pages

1. Create a new GitHub repository, for example `optimization-courses`.
2. Upload `index.html`, `styles.css`, and this `README.md` to the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.
6. Your site will be available at:

   `https://YOUR-GITHUB-USERNAME.github.io/optimization-courses/`

For a user site at `https://YOUR-GITHUB-USERNAME.github.io/`, name the repository exactly:

`YOUR-GITHUB-USERNAME.github.io`

## Customize

Edit `index.html` to add:

- Your name and affiliation
- Course names and semester details
- Lecture PDFs or slide links
- Assignment links
- Office hours and contact details
- GitHub, LinkedIn, or university profile links
